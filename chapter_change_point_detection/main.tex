%\section{Introduction revised by GPT 5.5}

%Memories allow us to predict the future based on the past. This requires the integration of previous experiences into an internal model of the world. Such integration is thought to occur during systems memory consolidation \citep{Squire}, where new experiences stored in the hippocampus are gradually integrated into neocortical knowledge structures. This is especially relevant when learning the statistical regularities of the environment \citep{statistical learning, consolidation, Schapiro stuff}. However, the world and its statistics are not stationary. When the environment changes, old experiences can become misleading, and the predictions that were useful before may no longer be appropriate. For example, if a commute used to be reliably quick but then roadworks start, the previous distribution of travel times is no longer the right basis for predicting how long the commute will take tomorrow.
%
%A principled solution to this problem is provided by Bayesian change point detection algorithms \citep{Adams2007}. These algorithms infer whether a change point has occurred and adjust predictions by weighting evidence from different possible intervals since the last change. In other words, they do not simply average all past observations, but maintain predictions conditional on different possible run lengths. This allows an agent to combine two requirements that are in tension: integrating evidence over long periods when the world is stable, but rapidly discounting old evidence when the world changes.
%
%Whether and how the brain implements such computations remains unclear \citep{bayesian brain hypothesis}. Exact Bayesian change point detection requires maintaining a posterior over possible run lengths and predictive distributions for each of them, which is computationally expensive. Several approximations have therefore been proposed. One approach is to reduce Bayesian updating to a delta-rule update with an adaptive learning rate \citep{Nassar2010}. Another is to approximate the Bayesian solution by a mixture of fixed-learning-rate estimators \citep{Wilson2013}. This latter result is especially important here, because it shows that Bayesian change point inference can be approximated by a set of predictors that differ in how strongly they weight recent observations relative to older ones.
%
%This connects change point detection to a central feature of systems memory consolidation. In the previous chapter (Ch.~\ref{ch:ppt}), we introduced the parallel pathway theory (PPT), a circuit mechanism for systems consolidation in which parallel pathways learn with different effective learning rates. In that model, fast pathways extract relatively specific and recent regularities, whereas slower pathways integrate over longer timescales and extract more stable semantic structure. Such a diversity of learning rates was introduced as a mechanism for building semantic generalizations at different levels of abstraction. Here, we suggest that the same diversity could also serve a different normative function: it could provide the set of parallel predictive estimates required to approximate Bayesian learning in changing environments.
%
%The key idea is therefore simple. Bayesian change point detection requires predictions based on different possible time windows into the past. Approximate algorithms show that such predictions can be implemented by a mixture of fixed-learning-rate estimators. A consolidation hierarchy with multiple pathways learning at different rates may already provide such a mixture. This suggests that learning-rate diversity in systems consolidation could be useful not only for extracting semantic structure, but also for adapting predictions when the statistics of the world change.
%
%In this chapter, we develop this idea formally. We first describe Bayesian change point detection in a simple statistical setting and show how predictions can be represented as a mixture over possible run lengths. We then relate this representation to approximations based on multiple fixed learning rates. Finally, we discuss how the diversity of learning rates proposed by PPT could provide a neural basis for such approximations, and what this implies for the role of systems consolidation in volatile environments.
